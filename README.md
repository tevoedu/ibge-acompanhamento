# Meu caminho no IBGE — ACA Iguatu

Painel estático de acompanhamento pessoal para o Processo Seletivo Simplificado IBGE 2026, função Agente Censitário Administrativo (ACA), localidade Iguatu/CE.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `ibge-aca-iguatu`).
2. Envie os arquivos `index.html`, `styles.css`, `app.js` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)` e salve.
6. Aguarde o endereço publicado aparecer na própria página de configurações do GitHub Pages.

Não precisa instalar nada, usar Node ou configurar servidor. O projeto usa somente HTML, CSS e JavaScript.

## Como o painel salva os dados

- As marcações são guardadas em `localStorage` no navegador em que o site for aberto.
- O progresso não sincroniza automaticamente entre celular, computador ou navegadores diferentes.
- O botão **Exportar progresso** baixa um arquivo JSON com as marcações para cópia de segurança.
- O site não recebe uploads e não envia informações para um servidor.
- Os avisos do navegador funcionam enquanto a página estiver aberta; o GitHub Pages, por ser hospedagem estática, não envia notificações push com o site fechado.

## Privacidade

O repositório publicado pode ser público. Nunca coloque CPF, identidade, certidões, atestados, dados bancários ou digitalizações pessoais nos arquivos do GitHub. Use uma pasta privada no computador ou em serviço de armazenamento privado.
